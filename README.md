# GLTF Scene Modeler

A mobile-first, browser-based 3D asset creation pipeline.

## Architecture
- `js/main.js` - Scene setup, logic
- `js/ui.js` - DOM bindings
- `js/viewGizmo.js` - ViewCube
- `js/topology.js` - Geometry math
- `js/sculptBrush.js` - Brush operations

## Running
Serve over HTTP: `python -m http.server 8080`
